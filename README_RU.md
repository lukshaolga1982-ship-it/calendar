# Teacher Calendar

Рабочая версия календаря преподавателя: месячный календарь, уроки, еженедельные серии, домашние задания, оплата, задолженности, ближайшие уроки и переключение часового пояса.

## Простая версия для GitHub Pages

В корне проекта находятся `index.html`, `styles.css` и `script.js`. Именно эти файлы можно загрузить в корень GitHub-репозитория: GitHub Pages найдёт `index.html` и откроет сайт без команды сборки.

Не удаляйте `styles.css` и `script.js` и не переносите их в другую папку, иначе `index.html` не сможет их подключить.

## Запуск

1. Установите Node.js 22 или новее.
2. Откройте папку в Visual Studio Code.
3. В терминале выполните `npm install`.
4. Выполните `npm run dev`.
5. Откройте адрес из терминала.

## Уже работает

- весь месяц в сетке из 6 недель;
- смена месяцев и возврат к текущему;
- одиночные и еженедельные уроки;
- домашние задания и отметка выполнения;
- оплата каждого урока и список задолженностей;
- добавление домашнего задания нажатием на урок ученика;
- удаление одного урока, предыдущей/следующей части или всей серии;
- обозначение онлайн- и офлайн-уроков;
- автоматическое увеличение строк календаря при большом количестве уроков;
- ближайшие уроки;
- сдвиг часового пояса UTC −/+ и отдельное время MSK;
- адаптация под телефон;
- демонстрационное сохранение в браузере.

## Firebase уже подключён

В проект уже добавлена конфигурация Firebase `calendar-65f48`. Чтобы вход и облачное сохранение заработали:

1. В Firebase Console откройте **Authentication → Sign-in method** и включите **Google**.
2. В **Authentication → Settings → Authorized domains** добавьте домен, на котором будет опубликован сайт.
3. Создайте **Cloud Firestore** в production mode.
4. Откройте **Firestore Database → Rules**, вставьте содержимое `firestore.rules` и нажмите Publish.
5. Если будут добавляться файлы к домашним заданиям, создайте Firebase Storage и опубликуйте `storage.rules`.

После входа данные автоматически сохраняются в `users/{uid}/calendar/main` и доступны только владельцу аккаунта. Без входа работает демонстрационный режим с сохранением в текущем браузере.

Полная архитектура повторяющихся серий, отдельных исключений и будущего расширения описана в `Teacher_Calendar_AI_Specification.md`.

Подробная пошаговая настройка Firebase со всеми кнопками, проверками и частыми ошибками находится в `FIREBASE_SETUP_RU.md`.
